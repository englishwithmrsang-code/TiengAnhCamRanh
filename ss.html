Bảng Công Thức So Sánh Hơn Của Tính Từ (Comparative Adjectives)

Tính Từ Ngắn

(1 âm tiết hoặc 2 âm tiết kết thúc bằng -y)

S + be + adj-er + than + ...
  • • tall ➔ taller
  • • happy ➔ happier (y ➔ ier)
  • • hot ➔ hotter (gấp đôi phụ âm)

Tính Từ Dài

(Có từ 2 âm tiết trở lên)

S + be + more + adj + than + ...
  • • beautiful ➔ more beautiful
  • • expensive ➔ more expensive
  • • difficult ➔ more difficult

Trường Hợp Đặc Biệt

(Tính từ bất quy tắc)

Học thuộc biến thể
  • • good ➔ better
  • • bad ➔ worse
  • • far ➔ farther / further

Bảng Công Thức So Sánh Hơn Của Trạng Từ (Comparative Adverbs)

Trạng Từ Ngắn

(fast, hard, early, late, high...)

S + V + adv-er + than + ...
  • • fast ➔ faster
  • • hard ➔ harder
  • • early ➔ earlier (y ➔ ier)

Trạng Từ Dài (-ly)

(Trạng từ hình thành bằng đuôi -ly)

S + V + more + adv + than + ...
  • • carefully ➔ more carefully
  • • fluently ➔ more fluently
  • • slowly ➔ more slowly

(Trạng từ bất quy tắc)

Học thuộc biến thể
  • • well ➔ better
  • • badly ➔ worse
  • • far ➔ farther / further
